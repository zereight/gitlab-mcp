# @zereight/gitlab-mcp

Search-friendly npm alias for [`@zereight/mcp-gitlab`](https://www.npmjs.com/package/@zereight/mcp-gitlab).

Both packages install the same GitLab MCP server and expose the same binaries:

- `zereight-mcp-gitlab`
- `mcp-gitlab`

```bash
npm install -g @zereight/gitlab-mcp
# or
npm install -g @zereight/mcp-gitlab
```

Documentation: [https://zereight.github.io/gitlab-mcp/](https://zereight.github.io/gitlab-mcp/)
